Prólogo: A Mudança de Paradigma

Da rigidez à inteligência adaptativa.

Automações tradicionais quebram na primeira exceção. O framework ILITHIA introduz o conceito de "Party": um grupo de agentes especializados que inferem soluções localmente e retêm aprendizado através de um sistema unificado de XP.

PASSIVA

Privacidade Absoluta

Nada sai da sua máquina. Desenvolvido para integração nativa com o Ollama, o motor de inferência opera em total isolamento. Modelos locais tomam decisões sobre o seu código proprietário sem riscos de segurança ou custos de API.

SISTEMA CORE

Progressão de Experiência

A cada build resolvido, a cada refatoração bem-sucedida, seus agentes ganham XP. Ao subirem de nível na "Skill Tree", eles desbloqueiam maior alocação de tokens de contexto e heurísticas mais sofisticadas para a próxima missão.

A Campanha Principal

O Diário de Missões

Como a orquestração de agentes autônomos se aplica a desafios reais de engenharia, infraestrutura e pesquisa.

Lvl 18 DevOps

Domínio da Infraestrutura

Invoque um agente para gerenciar deployments complexos. Configure rotinas dinâmicas onde a IA orquestra containers Docker, resolve conflitos de proxy no Nginx e automatiza a renovação de certificados via Certbot para APIs modernas de alta disponibilidade.

Lvl 24 Arquiteto

Integração Corporativa

Eleve a qualidade de projetos monolíticos ou microsserviços. Agentes especializados em Java e Spring Boot podem monitorar repositórios, sincronizar branches do Git, validar a lógica de novos endpoints e realizar reviews rigorosos em pull requests.

Lvl 30 Cientista

Fronteira Computacional

Escale para pesquisa acadêmica pesada. Mapeie agentes para executar e debugar algoritmos meta-heurísticos híbridos em scripts Julia. A IA monitora a eficiência do escalonamento, processa os logs e formata resultados diretamente para rigorosas publicações científicas.

O Grimório das Classes

A sintaxe por trás da magia.

A genialidade do ILITHIA está na sua familiaridade. Você não precisa aprender uma nova linguagem de automação; basta instanciar seus agentes como objetos comuns, definir seus papéis e lançá-los em quests assíncronas.

Explorar a API Completa → 
// Invocando a party de agentes locais
import { Agent, Quest, Party } from 'ilithia-core';

const devMage = new Agent({
  name: 'TerminalSage',
  role: 'SysAdmin',
  engine: 'ollama://llama3:8b'
});

// Definindo a missão de infraestrutura
const quest = new Quest({
  target: './docker-compose.yml',
  objective: 'Optimize Nginx reverse proxy routes'
});

const result = await devMage.execute(quest);

if (result.success) {
  devMage.grantXP(600);
  console.log(`Quest Clear! Agent reached Level ${devMage.level}`);
}
